# @arcanalabs/ui-components

Biblioteca de componentes shadcn para **Vue 3** (React/Angular/Svelte em breve).
Docs em construção.

```bash
npm install @arcanalabs/ui-components
```

```ts
import { ShadcnButton, ShadcnBadge, ShadcnInput } from "@arcanalabs/ui-components/vue";
import "@arcanalabs/ui-components/styles.css";
```

> `ShadcnInputMask` e `ShadcnDatePicker` usam a diretiva `v-maska`. Registre-a
> globalmente no app consumidor: `import Maska from "maska"; app.use(Maska)`.
